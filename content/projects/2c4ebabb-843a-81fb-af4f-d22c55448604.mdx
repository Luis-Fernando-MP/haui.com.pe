<h2 className="notion-heading_2 notion-color-default"><b className="notion-text-bold">🌊 CORAL</b></h2>

<p>Blog especializado en CSS avanzado e intermedio, desarrollado como proyecto final para el curso universitario de Diseño de Páginas Web. El objetivo fue construir un sistema de retroalimentación que permitiera explorar y compartir conceptos avanzados de CSS con la comunidad web, combinando contenido educativo con ejemplos de código interactivos.</p>

 <h3 className="notion-heading_3 notion-color-default"><b className="notion-text-bold">🎯 Sobre el proyecto</b></h3>

<p>CORAL es una aplicación estática construida con <b className="notion-text-bold">AstroJS</b>, pensada como un pequeño portafolio de artículos técnicos sobre CSS. Aunque su alcance es acotado, incorpora tecnologías y patrones modernos:</p>
 <ul className="notion-bulleted_list">
 <li className="notion-bulleted_list_item notion-color-default"><b className="notion-text-bold">View Transitions</b> para navegación fluida entre páginas.</li>
<li className="notion-bulleted_list_item notion-color-default"><b className="notion-text-bold">Previsualizadores de código embebidos (iframes)</b>, que permiten renderizar y visualizar snippets de CSS en tiempo real dentro de cada artículo.</li>
<li className="notion-bulleted_list_item notion-color-default">Arquitectura basada en contenido (<code className="notion-text-code">content collections</code>), separando la lógica de la aplicación de los posts del blog.</li>
 </ul>

<p>El proyecto no busca ser una single-page application ni un editor de código completo, sino un sitio estático ligero y rápido que prioriza la claridad del contenido y la experiencia de lectura.</p>
