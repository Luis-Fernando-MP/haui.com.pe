 <h1 className="notion-heading_1 notion-color-default">🚀 Guía de Instalación y Ejecución</h1>

<p>Pasos para instalar y ejecutar el proyecto en tu máquina local:</p>
 <ul className="notion-bulleted_list">
 <li className="notion-bulleted_list_item notion-color-default">Clona el repositorio:</li>
 </ul>

<hr className="notion-divider" />

```bash
git clone https://github.com/Luis-Fernando-MP/coral.git
cd coral
```

 <ul className="notion-bulleted_list">
 <li className="notion-bulleted_list_item notion-color-default">Instala las dependencias:</li>
 </ul>

<hr className="notion-divider" />

```bash
pnpm install
```

 <ul className="notion-bulleted_list">
 <li className="notion-bulleted_list_item notion-color-default">Inicia el servidor de desarrollo:</li>
 </ul>

<hr className="notion-divider" />

```bash
pnpm dev
```

 <ul className="notion-bulleted_list">
 <li className="notion-bulleted_list_item notion-color-default">Accede al proyecto en tu navegador en <code className="notion-text-code">http://localhost:4321</code>.</li>
