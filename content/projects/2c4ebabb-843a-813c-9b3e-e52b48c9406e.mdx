<h1 className="notion-heading_1 notion-color-default">🎯 Sobre el proyecto</h1>

<p>Smart Love Hotel es una plataforma moderna de reservas hoteleras ubicada en Lima, Perú. Desarrollada con tecnologías morder, ofrece un sistema eficiente y seguro para la gestión de reservas y administración hotelera.
El proyecto se centra en proporcionar una experiencia de usuario óptima mediante una interfaz intuitiva y funcionalidades avanzadas.</p>

<h1 className="notion-heading_1 notion-color-default">🚀 Guía de Instalación y Ejecución</h1>

<p>Pasos para instalar y ejecutar el proyecto en tu máquina local:</p>
 <ol className="notion-numbered_list">
 <li className="notion-numbered_list_item notion-color-default">Instala <a href="https://nodejs.org/en/" className="notion-text-href">Node.js v20</a></li>
<li className="notion-numbered_list_item notion-color-default">Instala PNPM globalmente:</li>
 </ol>

```shell
npm install -g pnpm
```

 <ol className="notion-numbered_list">
 <li className="notion-numbered_list_item notion-color-default">Clona el repositorio:</li>
 </ol>

```shell
git clone https://github.com/Luis-Fernando-MP/smartLove.git
cd smart-love-hotel
```

 <ol className="notion-numbered_list">
 <li className="notion-numbered_list_item notion-color-default">Instala las dependencias:</li>
 </ol>

```shell
pnpm install
```

 <ol className="notion-numbered_list">
 <li className="notion-numbered_list_item notion-color-default">Configura las variables de entorno:</li>
 </ol>

<ul className="notion-bulleted_list">
 <li className="notion-bulleted_list_item notion-color-default">Crea un archivo <code className="notion-text-code">.env</code> en la raíz del proyecto</li>
<li className="notion-bulleted_list_item notion-color-default">Copia las siguientes variables y configura sus valores:</li>
 </ul>

```shell
# API URL
NEXT_PUBLIC_API_URL=

# Clerk Authentication
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=
NEXT_PUBLIC_CLERK_SIGN_IN_URL=/sign-in
NEXT_PUBLIC_CLERK_SIGN_UP_URL=/sign-up
NEXT_PUBLIC_CLERK_AFTER_SIGN_IN_URL=/
NEXT_PUBLIC_CLERK_AFTER_SIGN_UP_URL=/
CLERK_WEBHOOK_USER_EVENTS=
CLERK_WEBHOOK_USER_EVENTS_DEV=

# Database
DATABASE_URL=
```

 <ol className="notion-numbered_list">
 <li className="notion-numbered_list_item notion-color-default">Ejecuta el proyecto en modo desarrollo:</li>
 </ol>

```shell
pnpm dev
```

 <ol className="notion-numbered_list">
 <li className="notion-numbered_list_item notion-color-default">Para compilar el proyecto para producción:</li>
 </ol>

```shell
pnpm build
pnpm start
```
